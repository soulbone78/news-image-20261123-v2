## Files
- main.py (Python 3.13 stdlib only): paints a 1024x1024
  PNG to $MAKEFUN_OUTPUT_DIR/entry.png (default /output).
- lemonmilk_data.py: baked Lemon Milk outlines (Bold + Regular),
  plain data, imported by main.py. Generated by
  extract_lemonmilk.py (kept here for the record); the .otf
  files are NOT shipped in the entry.
- creato_data.py: baked Creato Display outlines (Regular +
  Bold), plain data, imported by main.py. Generated by
  extract_creato.py (kept here for the record); the .otf
  files are NOT shipped in the entry.
- preview.png: render of main.py (this build's output).
